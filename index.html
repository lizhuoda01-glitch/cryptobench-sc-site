Benchmark Overview

测评任务简述

这里只保留必要背景：CryptoBench-SC 用一组可验证任务观察 Agent 是否能完成真实对称密码分析工作流。

当前启用五类任务

当前排行榜启用五类任务，覆盖结构理解、攻击还原、方案规划、工具实现与失败修复。

T1 结构理解 T2 攻击还原 T3 方案规划 T4 实现验证 T5 失败修复
问题范围以分组密码差分与线性分析为核心，少量扩展题用于观察泛化能力。
评分方式优先使用 schema、一致性检查、可执行 oracle 和证据边界检查。
展示重点排行榜、分项得分、稳定性和失效模式，而不是论文流程本身。

Analysis Framework

核心分析视角

从任务能力、过程质量、工具收益、保真风险、可靠性和人类基线六个维度观察模型表现。

GPT-5.5 Agent41.8
Claude Opus 4.7 Agent40.9
Gemini 3.1 Pro Agent33.1
DeepSeek-V4 Agent24.6
实现能力断崖
模型在 T4/T5 上显著掉分，说明把分析计划转化为可执行工件并完成失败修复仍是主要瓶颈。
重复运行不稳定
同一任务多次运行可能出现不同结果，pass^4 用于观察稳定成功率。
证据边界不足
部分提交能给出结论，但缺少可追溯日志、solver status 或 oracle 证据。
失败修复偏弱
诊断日志、定位根因并保持语义不变的修复能力仍弱于理解与规划。
A1
题型能力分解
比较 T1、T2、T3、T4、T5 的得分差异，定位理解、规划、构造与修复的能力边界。
A2
过程评分贡献
分析 final-only 与分层评分的差异，识别偶然正确但证据链不足的提交。
A3
工具配置影响
比较 model-only、tool-assisted 与 full-agent 在 T4/T5 上的收益。
A4
保真度惩罚
统计降轮、改攻击模型、误读 solver status 和 overclaim 等问题。
A5
可靠性 pass^4
每个模型-任务运行四次，分析稳定成功率而非单次最佳表现。
A6
人类基线差距
对照研究人员子集表现，判断任务是否位于合理研究构念范围内。
